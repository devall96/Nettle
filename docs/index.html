Nettle

Your Jellyfin, at full quality.

A fast, good-looking Jellyfin client for Windows, Linux and Android TV. It always plays the original file, so your server never has to transcode.

Newest version: see the release page
FOR THIS COMPUTER

Windows

Windows 10 or 11, 64-bit
Download installerNettle-win-Setup.exe Portable, no installNettle-win-Portable.zip
  1. Run the installer. It installs for your user only, no admin needed.
  2. If Windows says "Windows protected your PC" (Nettle isn't code-signed yet), click More info → Run anyway.
  3. Later versions install from Settings → Updates.
FOR THIS COMPUTER

Linux

AppImage: Ubuntu, Debian, Fedora, Arch…
Download AppImageNettle.AppImage
  1. Make it executable: Properties → Allow executing as program, or chmod +x Nettle.AppImage.
  2. Double-click it. Nettle offers to add itself to your applications menu.
  3. Later versions install from Settings → Updates.
FOR THIS DEVICE

Android TV

Google TV, onn 4K, Chromecast, Shield… (Android 9+)
Download APKNettle-AndroidTV.apk
Code for the
Downloader app
  1. On the TV, install Downloader (by AFTVnews) from the Play Store.
  2. Allow it to install apps: Settings → Apps → Security & restrictions → Unknown sources, turn on Downloader.
  3. In Downloader, enter this address:
    github.com/devall96/Nettle/releases/latest/download/Nettle-AndroidTV.apk    , then Install.
  4. Later versions install from Settings → Updates in Nettle.

These are the only files you need. The release page on GitHub also lists files ending in .nupkg, .json and RELEASES: Nettle's built-in updater reads those, so you can ignore them.

  • Original quality, alwaysDirect play of the original file. 4K, HDR10, Dolby Vision, Atmos and DTS go out as they are.
  • Live TV like cableA full guide, channel surfing and a tuning screen, with NostalgiaTV.
  • Private by designNo analytics or crash reporting. Nettle only connects to the servers you set up.
  • Same app everywhereWindows, Linux and Android TV share one version and the same features.
