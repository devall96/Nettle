**Nettle is now 1.0.** This release has no new features: it is 0.6.0 with a new number, plus what's needed for a Microsoft Store version.

### 🔢 Why the jump from 0.6 to 1.0
- **It has earned it.** Nettle has been used every day on several devices, on Windows, Linux and Android TV, and it has been stable. A "0." in front of the version says "expect it to break", and that no longer matches how it behaves.
- **It's time for more people to try it.** So far one person has tested Nettle. It's ready for feedback from other people, on other hardware, and 1.0 is the invitation: if something goes wrong on your setup, please [open an issue](https://github.com/devall96/Nettle/issues/new?template=bug_report.md).
- **The Microsoft Store needs it.** The Store doesn't accept version numbers that start with 0. Rather than give the Store copy a different number from every other copy, all of Nettle moves to 1.0.0 together, so Windows, Linux, Android TV and the Store keep sharing one version.
- **What 1.0 doesn't mean:** that Nettle is finished, or tested everywhere. It is still written by an AI coding assistant and directed and tested by one person. The [known limitations](https://github.com/devall96/Nettle#known-limitations-100) still apply.

### 🪟 Microsoft Store
- **A Microsoft Store version of Nettle has been submitted and is in Microsoft's review.** If it passes, you'll be able to install Nettle from the Store with no "Windows protected your PC" warning, and Windows will keep it up to date.
- The Store copy is the same app. Its own updater is switched off, because the Store does the updating; **Settings → Updates** says so there.
- If you already use the installer version, a Store copy finds your settings and saved sign-ins.
- Nothing changes for the installer, the portable copy, Linux or Android TV.

### 🔒 Privacy
- Nettle now has a written [privacy policy](https://devall96.github.io/Nettle/privacy.html). It says what the README always has: Nettle collects nothing and only connects to the servers you enter.
